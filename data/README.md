# Data

This directory contains the source and derived datasets used to construct the LNG maritime multilayer network.

Some files may not be included in the repository because of licensing restrictions or file-size considerations.

## Source data

* `LNG_terminal.csv` — LNG-T3 terminal data.
* `LNG_tanker_voyage.csv` — LNG-T3 voyage-level data for 2020–2024.
* `PortWatch_28_geometry_registry_v12.xlsx` — sources, reference coordinates and construction methods for the 28 chokepoint geometries.
* `PortWatch_28_chokepoints_geometry_working_v10.geojson` — final Polygon and MultiPolygon geometries used to identify route crossings.

## Reconstructed routes

Generated by `postprocess_searoute_1037.py`:

* `LNG_1037_routes_with_final_chokepoints_v1.geojson` — 1,037 SeaRoute maritime routes with their final chokepoint assignments.

## Derived data

Generated by `01_prepare_voyages_and_nodes.py`:

* `LNG_voyage_node_matching_v1.xlsx` — voyage records matched to canonical LNG terminal IDs.
* `LNG_multilayer_nodes_v1.csv` — final table of 159 terminals and 28 chokepoints.

Generated by `build_multilayer_network.py`:

* `LNG_multilayer_edges_monthly_v1.csv` — directed and weighted monthly network edges.
  lsd.
* `LNG_multilayer_monthly_QA_v1.csv` — monthly network and quality-control summary.

The final network contains 187 nodes, 1,037 reconstructed routes and 60 monthly periods from January 2020 to December 2024. After removing three duplicated export records, 8,642 laden LNG voyages are used in the analysis.
