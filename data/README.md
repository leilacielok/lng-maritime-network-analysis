# Data

This directory contains the source and derived datasets used to construct the LNG maritime multilayer network.

Some files may not be included in the repository because of licensing restrictions or file-size considerations.

## Source data

* `LNG_terminal.csv` — LNG-T3 terminal data.
* `LNG_tanker_voyage.csv` — LNG-T3 voyage-level data for 2020–2024.

## Curated chokepoint data

The following files were manually compiled and validated as part of the study:

* `PortWatch_28_geometry_registry.xlsx` — documentation of the sources, reference coordinates, methodological decisions and derivation parameters for the 28 chokepoints.
* `PortWatch_28_chokepoints_geometry.geojson` — final operational Polygon and MultiPolygon geometries compiled or derived from the sources documented in the registry.

## Reconstructed routes

Generated by `02_postprocess_searoute_1037.py`:

* `LNG_1037_routes_with_final_chokepoints.geojson` — 1,037 SeaRoute maritime routes with their final chokepoint assignments.

## Derived data

Generated by `01_prepare_voyages_and_nodes.py`:

* `LNG_voyage_node_matching.xlsx` — voyage records matched to canonical LNG terminal IDs.
* `LNG_multilayer_nodes.csv` — final table of 159 terminals and 28 chokepoints.

Generated by `03_build_multilayer_network.py`:

* `LNG_multilayer_edges_monthly.csv` — directed and weighted monthly network edges.
  lsd.
* `LNG_multilayer_monthly_QA.csv` — monthly network and quality-control summary.

The final network contains 187 nodes, 1,037 reconstructed routes and 60 monthly periods from January 2020 to December 2024. After removing three duplicated export records, 8,642 laden LNG voyages are used in the analysis.
